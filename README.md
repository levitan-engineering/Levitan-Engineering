# לויתן הנדסה

אתר תדמית ומכירה בעברית עבור לויתן הנדסה, בנוי ב־Next.js ו־React ומיוצא כאתר סטטי מהיר.

## פיתוח מקומי

```bash
pnpm install
pnpm dev
```

האתר זמין ב־`http://localhost:3000`.

## בנייה ופריסה

```bash
pnpm build
```

קבצי הפריסה נוצרים בתיקיית `out`. הפרויקט כולל הגדרות מוכנות ל־Netlify ול־Vercel. הוא אינו משתמש ב־Firebase כרגע.
